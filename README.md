# UM-Fest 2.0 · 28 November 2026

Website lorong pameran 3D untuk **UM-Fest 2.0** di Ma'had Tahfizh Ummahatul Mu'minin, Balaraja, Tangerang.

Website ini dibuat oleh **Presentdien × 521 Coffee Cart**.

## Isi repo
- `index.html`: seluruh website dalam satu file (gambar dan font sudah disematkan).
- `.nojekyll`: memberi tahu GitHub Pages agar file disajikan apa adanya.

## Cara memperbarui
1. Ganti `index.html` dengan versi terbaru.
2. Commit ke branch `main`. GitHub Pages akan memperbarui website dalam 1–2 menit.
